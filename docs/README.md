# GoreeCloud App Store documentation

This directory is the canonical home for human-readable repository documentation. `README.md` remains the root entry point; machine-readable build, platform, and source-control controls remain at repository root where required.

## Canonical product records

- `SPECIFICATIONS.md` — product and engineering requirements.
- `ARCHITECTURE.md` — authority boundaries and runtime design.
- `FEATURES.md` — current capability overview.
- `IMPLEMENTED-FEATURES.md` — implemented capability authority.
- `PLANNED-FEATURES.md` — planned, blocked, and deferred capability authority.
- `CHANGELOGS.md` — repository-local changelog.
- `BENEFITS.md` — supportable product and platform benefits.
- `COMPETITIVE-OBJECTIVES.md` — differentiation and benchmark objectives.
- `BRANDING.md` — branding-consumer mappings and provenance.
- `USER-MANUAL.md` — current user/developer behavior and limitations.
- `NOTES.md` — current repository-level development and maintenance notes.
- `PRIVACY.md` — current Development privacy boundary.

## Supporting documentation

- `RELEASE-CHANNELS.md` and `CHANGELOG.release-channels.md` — release-channel design and checkpoint history.
- `android-installed-state-observation.md` — exact-package installed-state observation boundary.
- `channel-policy-boundary.md`, `channel-policy-status.md`, and `channel-claims.example.txt` — Development channel authorization notes.
- `package-delivery-pre-handoff-policy.md` and `package-delivery-read-only-preflight.md` — fail-closed delivery policy documentation.
- `release-channel-rollout.md` — account-dependent Stable, RC, Beta, Development, and Debug channel authorization foundation.
- `plans/goreecloud-app-store-update.md` — migrated detailed capability plan.

Repository security guidance is maintained at `.github/SECURITY.md`.

Repository documentation is Development evidence unless a record explicitly cites stronger accepted authority.
